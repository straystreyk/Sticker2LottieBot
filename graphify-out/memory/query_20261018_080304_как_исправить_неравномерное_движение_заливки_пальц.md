# Q: Как исправить неравномерное движение заливки пальца при конвертации Jitter Lottie в Telegram TGS?

## Answer

В finger-1 обнаружены три layer position-трека 11, 36 и 42 с отдельными easing-кривыми для X и Y. Telegram применяет первую кривую ко всем координатам. Исправление преобразует такие комбинированные position-свойства без spatial tangents в стандартные split position X/Y и сохраняет easing каждой оси. Нормализация выполняется и при обычной конвертации, и при auto-fix. Проверка исходного файла дала 512x512, 60 fps, 2.99 s, 14,313 bytes и Telegram compatibility без предупреждений.
