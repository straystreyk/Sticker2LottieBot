# Q: Почему SVG с CSS-классами становится чёрным при конвертации в TGS?

## Answer

Основной bundled lottie_convert игнорировал цвета из SVG style-классов и создавал только чёрную заливку. Перед запуском бинарника CSS presentation attributes теперь встраиваются в элементы как fill, stroke и opacity. Fallback-парсер также исправлен: отсутствующий stroke больше не считается чёрным. На Artboard 1.svg результат содержит исходные #011839 и #7738c8; 13 тестов проходят.
